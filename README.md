**CodigoLimpio_ContenidoAudiovisual**

Unidad 4. Programación Limpia

Descripción de la actividad: 

**Objetivo:** 

1. Terminar el sistema de "Contenido Audiovisual" gestionando archivos, incorporando información sobre Películas, Series de Televisión, Documentales, Actores, Temporadas e Investigadores. 
2. Utilizar principios de código limpio, realizar refactorización y aplicar SOLID para mejorar la calidad y mantenimiento del código. 
3. Establecer un patrón de diseño que separe el modelo, la vista y el controlador (MVC). 
4. Crear pruebas unitarias que abarquen las funciones principales del sistema mediante JUnit.
